1. Introduction

Modern developers are often pressed for time when developing software, and are fundamentally lazy in a way only programmers understand. This leads them to take shortcuts, including the use of generative AI, to complete their work faster. While generative AI is a useful tool, it must be accompanied by careful manual review to ensure the generated code matches the objectives of the developer, but also to ensure the code is free of security vulnerabilities.
