4. MoniTAal 专章：论文方法与代码实现映射

MoniTAal 当前仓库更像 timed automata monitor kernel：它不从 MITL 文本直接生成 automata，而是解析/接收 positive 和 negative timed automata，再对 timed observations 做在线状态估计与 verdict 更新。
