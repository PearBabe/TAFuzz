                                <name> <path>
  -p [ --pos ] arg              <name of template> <path to xml file> : 
                                Property automaton.
  -n [ --neg ] arg              <name of template> <path to xml file> : Negated
                                property automaton.
  -t [ --type ] arg (=concrete) Input type (concrete or interval) default = 
                                concrete.

  -u [ --inclusion ]            Enable inclusion checking for duplicate states
  -c [ --clock-abstraction ]    Enable abstraction of inactive clocks

  -o [ --print-dot ]            Prints the dot graphs of the given automata.
