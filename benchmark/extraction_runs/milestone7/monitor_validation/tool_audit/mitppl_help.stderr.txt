Usage: mitppl <in_spec_file> --{fin|inf} [out_file --{tck|xml} [--{noflatten|compflatten}]] [--debug] [--noback]

--debug: pauses to see diagostic info
--noback: disables symbolic backward analysis (for Pnueli modalities / MITL modalities with <l, u>; no effect if --noflatten is set)

If [out_file ...] is NOT specified, the built-in DBM fixpoint algorithm checks the (Buechi) emptiness of the
(monolithic flattened) product automaton (i.e. the satisfiability of the input formula && TA_div && model M).
