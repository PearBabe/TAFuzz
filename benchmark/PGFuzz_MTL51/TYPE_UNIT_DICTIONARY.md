# 源码数据类型、单位与坐标语义词典

## 阅读前必须知道的术语

- `data_type`（data type，数据类型）：说明命题绑定值在 ArduPilot/PX4 源码中怎样存储，或由什么表达式、结构和操作产生。它决定值能否直接读取，以及应使用布尔、整数、浮点、枚举还是复合值比较。

- `unit_coordinate`（unit and coordinate semantics，单位与坐标语义）：说明命题绑定值的量纲、比例、方向、参考点和坐标系。两个数即使都写成“米”，参考点不同也不能直接比较。

- `current_input_type`（current input type，当前输入类型）：说明 PGFuzz 作者依赖输入在当前冻结固件参数元数据中的类型。它属于测试输入身份，不等同于命题绑定变量的源码类型。

- `current_input_unit`（current input unit，当前输入单位）：说明上述当前输入参数的元数据单位。它用于审核变异值的量纲和边界，不直接证明某个命题变量可观察。

- C/C++：C 与 C++ 两种系统编程语言；ArduPilot 与 PX4 的当前任务源码主要使用 C++。`源码标识符`是代码中必须原样保留的类名、类型名、字段名或函数名，例如 `AP_Float` 和 `vehicle_command_ack_s`，旁边的中文只解释意义，不改名。

- `bool`/`boolean`（布尔量）只能表达假或真；`enum`（enumeration，枚举）用整数代码表达有限状态集合；`bitmask`（位掩码）用一个整数的不同位表示多个选项；`latch`（锁存）表示触发后持续保存到重置。

- `int`（signed integer，有符号整数）允许负值，`uint`（unsigned integer，无符号整数）不允许负值；8、16、32、64 表示位宽。`float32` 是 32 位单精度浮点数，`float64` 是 64 位双精度浮点数；浮点比较要考虑舍入、非数值和无穷值。

- 长度单位：`m` 是 metre（米），`cm` 是 centimetre（厘米），`mm` 是 millimetre（毫米）。时间单位：`s` 是 second（秒），`ms` 是 millisecond（毫秒），`us`/`µs` 是 microsecond（微秒）。频率单位 `Hz` 是 hertz（赫兹，即每秒次数）。

- 角度/角速度/角加速度：`deg` 是 degree（度），`rad` 是 radian（弧度），`deg/s` 与 `rad/s` 是角速度，`deg/s/s` 与 `rad/s/s` 是角加速度。`s/rad`、`s²/rad`、`1/rad` 是包含角度倒数量纲的系数，不能当成单纯时间。

- `AMSL`（Above Mean Sea Level，平均海平面以上）是绝对海拔参考；`Home` 是飞行器记录的返航基准点；`NED`（North-East-Down，北-东-下）是 x 向北、y 向东、z 向下为正的局部坐标系；`WGS84`（World Geodetic System 1984，1984 世界大地测量系统）是全球经纬度基准。

- `EPH` 字段在本任务中表示 estimated horizontal position error（水平位置估计误差）；`PWM`（Pulse Width Modulation，脉宽调制）常用微秒脉宽承载舵机或电机命令。二者都不能只凭数值大小推断其他物理量。

- `Pa`（pascal，帕斯卡）是压力单位；`V`（volt，伏特）是电压单位；`gauss`（高斯）、`mGauss`（毫高斯）和 `mGauss/A`（毫高斯每安培）用于磁场或磁场校准；`%` 是百分比；`norm`（normalized value，归一化值）是无量纲比例。

- `degC` 是 degree Celsius（摄氏度）的单位标签；原始值 `celcius` 是作者或参数元数据对 Celsius 的不规范拼写。本词典保留原拼写作为证据，同时明确它仍表示摄氏温度。

- “速率方向”由坐标轴和符号共同决定。例如 NED 的竖直速度向下为正；“参考系”说明数值相对哪个原点、轴和参考面。只有量纲、尺度、方向和参考系都一致的值才能直接比较。

## 覆盖与使用规则

本词典从 `term_source_bindings.json` 的 227 条命题绑定记录和 `current_input_identity_map.json` 的 356 条当前输入身份记录中精确收集原值。四类分别覆盖 100、61、7、28 个唯一原值，共 196 行；每类都把空字符串保留为“未填写”，没有删除或擅自补值。`explanation_zh` 是中文解释，`audit_effect_zh` 是该原值对真值条件、类型转换、参数变异或证据判断的影响。
